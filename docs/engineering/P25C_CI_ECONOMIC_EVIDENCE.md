# P25-C — Hermetic economic evidence and Azure OIDC isolation

The `Economic Specification Evidence` CI job runs for **every PR and every main push**, without application installation or cloud credentials. It computes the merge-base diff, fails closed if the base cannot be determined, and for changed economic source paths requires all three changed artifacts: normative LONGO/related text, independent JSON golden, and independent reference regression. Negative fixtures in `test_p25c_economic_delta_gate.py` prove that a code-only economic change, docs-only justification, or fake unit test cannot bypass the gate.

This is a **workflow failure gate**; it only becomes a **mandatory merge protection** once the repository owner configures the corresponding required status check in GitHub branch rulesets. Require at minimum `Tests`, `Lint`, `Type Check`, `Dependency Lock (Docker parity)`, `Formalism Reference (independent)`, `Formalism Reference Py3.12`, `Formalism Reference Py3.13`, and `Economic Specification Evidence`. The conditional `MCP Proxy (standalone)` job should not be configured as an unconditional required check without redesigning its skip semantics.

Deploy runs separately under `deploy.yml`; the reusable workflow checks `AZURE_CLIENT_ID`, `AZURE_TENANT_ID`, and `AZURE_SUBSCRIPTION_ID` without printing values. If any are absent, deployment fails with `BLOCKED_CONFIGURATION`, never silently reports success, and leaves offline numerical CI independently runnable. GitHub OIDC federation also requires the real Azure federated credential issuer, subject and audience matching repository/environment; these cloud-side settings cannot be provisioned by this PR.

**Limitations:** a changed fixture is necessary but does not alone prove semantic correctness—Codex/human review, independently hand-verified goldens and non-GO certification gates remain mandatory. Existing external deploy credentials are not claimed healthy without an authenticated deployment run. The remaining blocker may require an organization administrator.
