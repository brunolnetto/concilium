# P18-C3 — opt-in Skill06 consumption preview from the exact Skill05 witness

**Package:** P18-C3, issue #18. Depends on P18-C1/C2 in stacked PR #142. This draft keeps the legacy financial authority intact.

## Contract

- Opt-in only through `inputs["p18_consumption_preview_enabled"] is True`. Missing/false means the legacy Skill06 flow remains unchanged, after invalidating a stale P18 sidecar. Non-boolean selectors are rejected.
- Reconstruct the exclusive P17 ledger from each canonical `RecursoContrato.p16_global_assignment` witness generated by Skill05. Validate identities, currency, exact tariff, complete contiguous calendar, per-activity-to-aggregate demand, active-chain coverage and exact cost totals.
- Recompute every pool posting using the existing P16 `ExactPoolResult` + `book_exact_pool` path and compare the rebuilt postings to the serialized witness. Missing, forged, duplicated or mixed pool evidence fails closed.
- Run the P18-C1/C2 catalog-backed Skill04 preview and serialize exact rational values, source IDs, weeks, physical/price units, price provenance, explicit currency, and exclusive financial postings into the separate `CanonicalModel.p18_consumption_preview` sidecar. The current `Insumo` schema and `load_catalogo()` output do not preserve a currency field, so the opt-in caller must supply `inputs["p18_catalog_price_currency"]` as an explicit declaration matching every exact Skill05 witness. Missing or conflicting currency fails closed. The sidecar records `currency_source="EXPLICIT_RUNTIME_DECLARATION_CATALOG_SCHEMA_HAS_NO_CURRENCY_FIELD"`; this is an operator declaration, not catalog-derived provenance.
- On success emit only an `AVISO` that the preview was recorded; do not write legacy sale/cost/margin fields, alter Skill06 pricing inputs, infer operating hours, or emit a GO certificate. An invalid explicit opt-in returns `ERRO` before Stage 3 consolidates financial results.

## Deliberate limits

This is not invoice/receipt evidence or actual usage. P16 is exact only conditional on fixed physical weekly demand, and this is a planned closed-scope consumption preview. It is not a joint RCPSP optimum, not an independent project certificate, and not `PROJECT_GO`. Hourly fuel/material rates remain unsupported unless a future stage provides explicitly matched operating-hour observations.

## Validation

The bridge and wiring tests were added but **have not been executed** on this draft head. GitHub Actions is intentionally not enabled per maintainer decision. Prior 287-case P14/P15/P16 stack evidence does not validate P18-C1/C2/C3. Issue #18 remains open. The current catalog schema has no currency field; the explicit run-level declaration is an interim input contract, not proof derived from each source record.
